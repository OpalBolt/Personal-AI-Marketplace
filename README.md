# Personal AI Marketplace

Personal AI tools — evidence-first coding agents and workflow skills.

## Plugins

| Plugin | Description |
|--------|-------------|
| **blip** | Evidence-first coding agent with adversarial review and SQL-tracked verification |
| **blip-copilot** | Blip specialized for GitHub Copilot CLI |
| **workflow-skills** | Git commit, issue, and PR skills following Conventional Commits |
| **interview-me** | Spec interviewer that produces clean specification documents |
| **skill-creator** | Create and improve skills through guided iteration |
| **refine-issue** | Fetch and refine GitHub issues into implementation-ready specs |
| **markdown-writer** | Create consistent markdown documents following KISS principles |
