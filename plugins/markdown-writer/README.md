# Markdown Writer

Ensure consistency when creating markdown documents across your projects.

## Installation

Install from Personal AI Marketplace:

```bash
marketplace install markdown-writer
```

## Usage

This skill triggers automatically when you:
- Create any markdown files
- Write README files
- Create documentation folders
- Work with .md files

## What It Does

The markdown-writer skill ensures your markdown documents are:

- **Concise** — KISS principle, no fluff, only important content
- **Consistent** — Follows established conventions in your project
- **Well-organized** — Splits long docs into multiple files
- **Professional** — Relaxed but not posh tone
- **Minimal** — Uses emojis only where they add value (tables, status indicators)

## Features

- Automatically identifies and filters out unrelated content
- Suggests splitting long documents into multiple files
- Prefers doc/ folders for multi-file documentation
- Respects existing markdown conventions in your project
- Maintains a balance between being informative and concise

## Philosophy

Good markdown documentation should be easy to scan, quick to understand, and free of unnecessary verbosity. This skill helps maintain that standard consistently.
