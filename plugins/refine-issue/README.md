# Refine Issue

A skill for refining GitHub issues through focused interviews, transforming vague issue descriptions into implementation-ready specifications.

## What it does

Takes an existing GitHub issue (by number or URL) and guides you through a structured interview to:

- Clarify the problem and desired outcome
- Identify edge cases and constraints  
- Define acceptance criteria
- Add technical context and implementation hints

The result is a refined issue description that can be posted back to GitHub or saved locally.

## Usage

```bash
/skill:refine-issue 42                                          # By issue number
/skill:refine-issue https://github.com/owner/repo/issues/123    # By URL
```
